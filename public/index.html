STRESS TEST LAB

算法对数器

生成可复现的随机数据，用最直接的参考实现逐例验证 Java、C++、Python 算法。

仅运行可信代码源码会在本机临时目录编译执行，完成后自动删除；本工具不是安全沙箱。
01

选择算法

上传待测算法与独立的朴素参考实现

支持 .java / .cpp / .py，最大 1 MB
建议使用遍历、排序等容易确认正确的写法
函数模式接口约定
Python: def solve(data: str) -> str
C++:    std::string solve(const std::string& data)
Java:   public static String solve(String data)

函数模式不会调用上传文件原有的 main；Python 还会过滤顶层测试语句。

02

生成测试数据

AI 辅助

AI 最多补充 20 个针对性边界样例，其余批量数据仍由本地生成器完成。上传的算法源码和数据要求会发送给所配置的模型服务。
