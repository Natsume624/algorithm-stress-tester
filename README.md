# 算法对数器

本地 Web 工具：批量生成可复现的随机输入，把待测算法和独立的朴素参考实现逐例运行并比较输出。支持 `.java`、`.cpp`、`.py`，两边可以使用不同语言。

## 启动

需要 Node.js 20+，并按需安装 `python`、`g++`、`javac/java` 且加入 PATH。

```powershell
cd "C:\Users\m1556\Documents\ChatGPT\对数器"
npm start
```

浏览器打开 <http://127.0.0.1:3210>。

也可以直接双击项目目录中的 `启动对数器.cmd`。`npm start` 必须在包含 `package.json` 的项目目录运行；如果终端当前位于 `C:\Users\m1556`，npm 会报 `ENOENT`。

## 两种执行模式

- 程序模式：按竞赛程序运行，测试输入写入 stdin，读取 stdout。
- 函数模式：只调用约定算法函数，不调用源码自带的 `main` 或对数器。接口为 Python `solve(data: str) -> str`、C++ `std::string solve(const std::string&)`、Java `public static String solve(String)`。函数名可在界面修改。

Python 函数模式仅加载 import、函数、类及简单常量定义，过滤顶层测试语句；C++ 会在编译时重命名已有 `main`；Java 会生成独立 Runner。因此，上传文件中已有的随机测试或对数器不会成为判定依据。

## 自然语言数据要求

用户直接描述数据约束，例如：

```text
长度 1 到 50、元素范围 [-100,100]、相邻两项不相等的整数数组
长度为 20、元素互不相同、严格递增的正整数数组
长度不超过 100、只包含奇数的整数数组
长度 5 到 30、相邻字符不同的小写字符串
```

程序会解析数据类型、规模、取值范围、相邻不等、全局互异、递增/递减、正负数和奇偶限制。结果页会列出程序实际理解到的约束；冲突或无法满足的要求会直接报错，而不会生成不合规数据。

## AI 辅助

勾选“启用大模型辅助”后可选择：

- OpenAI Responses API：例如 `https://api.openai.com/v1`
- OpenAI-compatible：适用于兼容 Chat Completions 的云服务、LM Studio、vLLM 等
- Ollama：默认地址 `http://127.0.0.1:11434`

填写 API 地址、模型名称和可选的 API Key。模型会把自然语言要求转为生成计划，补充最多 20 个针对性边界输入，并基于待测源码分析时间与额外空间复杂度；其余大量随机数据仍由本地生成器完成。API Key 只用于当前请求，不会保存到磁盘或浏览器存储中。

如果勾选回退选项，模型连接失败时会继续使用本地规则并在结果页显示警告。请注意，启用 AI 会把数据要求和待测算法源码发送给所配置的模型服务。

随机种子可复现失败样例。测试数上限 10,000，单例超时范围 100–10,000 ms，输出上限 1 MB。

全部测试通过后，结果页会显示待测算法的时间复杂度和额外空间复杂度估算，并给出判断依据与置信度。该结果基于排序、循环嵌套、图遍历、二分、递归及动态容器等静态代码特征，不是形式化证明；复杂数据结构或摊还分析仍建议人工复核。

> 安全提示：工具会执行上传源码，只应运行可信代码。进程有超时限制，但这不是操作系统级安全沙箱。
